## DeepSeek V4 Pro Releases with 1.7T Parameters, Targeting Claude Code's Lead

DeepSeek shipped V4 Pro 0813 on August 12, initially API-only via OpenRouter, with the full 1.7-trillion-parameter weights (893 GB) subsequently published on Hugging Face. Bloomberg reported that DeepSeek is explicitly positioning the model to challenge Anthropic's Claude Code dominance in the agentic coding market. Simon Willison noted the model is available at three reasoning levels and shows varied behavior across them; Two Minute Papers framed the release as another "DeepSeek moment," referring to the pattern of Chinese labs releasing capable open-weight models that reset Western cost assumptions.

**Why it matters:** A 1.7T open-weight coding model competitive with Claude Code dramatically changes the build-vs-buy equation for any developer team willing to operate infrastructure at that scale.
