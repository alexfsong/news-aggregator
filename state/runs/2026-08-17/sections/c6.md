## Meta's Muse Glimmer: 30B Open-Weight Multimodal Model Built for Agentic Use

Meta released Muse Glimmer, a 30-billion-parameter vision-language model under an Apache 2.0 license—a notable liberalization from the Llama license. The architecture is a dense 28B text decoder paired with a 2B ViT-style perception encoder; it uses hybrid attention (sliding-window plus full-attention layers) and includes an optional speculative-decoding drafter tuned for structured content like code generation. Meta launched with day-0 support in Hugging Face Transformers, llama.cpp, vLLM, and Inference Endpoints. Simon Willison highlighted its benchmark performance on end-to-end agentic tasks (MCP-Atlas, SWE-Bench, τ-bench) and called the Apache 2.0 licensing a meaningful improvement over prior Llama terms. The model targets local deployment for agentic pipelines that need multimodal reasoning without API dependence.

**Why it matters:** A permissively licensed 30B multimodal model that benchmarks well on agentic tasks gives developers a credible self-hosted alternative to closed API models for vision-capable agent workflows.
