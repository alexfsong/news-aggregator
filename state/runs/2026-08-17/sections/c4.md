## OpenAI Previews Ultrafast API Tier: GPT-5.6 Sol at 750 Tokens/Second via Cerebras

OpenAI launched a preview of "Ultrafast" mode for its API, running GPT-5.6 Sol on Cerebras hardware at speeds up to 14× faster than the standard tier—reaching up to 750 output tokens per second. The company simultaneously published a builder's guide positioning GPT-5.6 as the preferred model for cost-efficient agentic pipelines, and expanded access: improved GPT-5.6 Sol rolls out to ChatGPT subscribers while GPT-5.6 Luna, a lighter variant, is now available for free users with unlimited everyday queries. Simon Willison put GPT-5.6 Sol Ultra through its paces building a game using Codex in multi-agent mode and found the output substantially better than a comparable Claude-only run.

**Why it matters:** Ultra-fast inference at this token rate makes real-time agentic loops economically viable for the first time—expect a wave of applications that previously stalled on latency to ship in the next quarter.
