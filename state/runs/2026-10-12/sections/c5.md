## OpenAI Launches GPT-6 Family with Intelligent UI, Unveils GPT-6.1 Sol at DevDay 2026

OpenAI rolled out GPT-6 globally in ChatGPT alongside "Intelligent UI" — an interface layer delivering faster responses with embedded visuals and interactive experiences. Simultaneously, OpenAI introduced GPT-6.1 Sol, positioned as a lower-cost tier offering near-GPT-6-Astra capability for coding, computer use, and professional tasks at one-fifth the standard API token price. At DevDay 2026, OpenAI announced over 20 updates including GPT-6 Astra, Codex improvements, and new developer APIs. A practical model guide was also published. Early enterprise results are notable: Asana reported a 76x cost reduction and 5x speed increase in browser agent tests using GPT-6.1 Sol. The HN thread on the GPT-6 launch drew 756 points and 458 comments.

**Why it matters:** The GPT-6.1 Sol pricing — a high-capability model at one-fifth flagship cost — raises competitive pressure on every other API provider, including Anthropic's Claude lineup.
