## OpenAI Launches Agents API, Voice API, Data Agent, and Government AI Access

On September 10, OpenAI shipped a cluster of platform releases. The Agents API is a managed cloud service built on the Codex harness, designed for orchestrating long-running agentic sessions with tool use — eliminating the need to build and host your own agent infrastructure. Alongside it, GPT-Live-1 brings full-duplex voice to the API with custom voice support and telephony integration. A new Data Agent in ChatGPT Work lets users connect company data and build dashboards via natural language. ChatGPT for Financial Services bundles built-in financial data with GPT-6 Astra for research and client materials. Finally, a GSA partnership gives eligible US federal, state, local, and tribal governments zero license fees and 50% off usage, plus expanded cyber defense support.

**Why it matters:** The Agents API in particular lowers the barrier to production agentic deployments significantly, and the government pricing signals that OpenAI is actively competing to become critical infrastructure for public-sector operations.
