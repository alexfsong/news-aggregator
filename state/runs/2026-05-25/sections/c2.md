## Anthropic Launches "Code with Claude" Platform with Managed Agents and Small-Business Tier

At a two-day developer event in London (May 19–20), Anthropic unveiled Code with Claude — an agentic coding platform featuring managed agents, proactive workflows, and a "Capability Curve" that lets developers dial AI autonomy up or down. The same week, Anthropic launched a Claude for Small Business plan and deployed Claude Code to US state and local governments. On the legal side, Anthropic released more than 20 practice-area connectors and 12 plugins for law firms, with Reuters reporting expanded tooling for lawyers. MIT Technology Review noted the event drew debate about how much autonomy developers should cede to AI systems writing production code.

**Why it matters:** Anthropic is simultaneously pushing Claude into developer infrastructure, the SMB market, government, and regulated professions — widening the competitive surface against GitHub Copilot and OpenAI Codex in a single product cycle.
